<objective>
Collapse the four `pio` execution paths onto one mockable seam, then prove all 12 tool handlers through it.

Purpose: D-09 assumes a single `runPioCommand` seam, but B-4 shows the async branches of build, upload, and test call the child-process executor inline. Without this refactor the integration suite would pass while three real handlers spawn a live `pio` — the exact failure T-3-01 describes. This plan's tracer closes the seam on one handler end to end, then expands to every tool.
Output: Three refactored handlers, a child-process guard wired into the integration project, and eight integration suites covering the 12 tools.
</objective>

    - DTR/RTS overrides (--upload-port with explicit port, use esptool.py direct)

    **Area 3 — ESP32 Runtime Issues:**
    - Boot loops (check serial monitor output, verify boot mode pins)
    - Crash dumps / Guru Meditation errors (decode with espexceptiondecoder)
    - Watchdog timeouts (check task blocking, increase WDT timeout)
    - Brownout detector (insufficient power supply, check USB cable)

    - Board definitions not found (pio boards list, update platform)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent → SKILL.md instructions | Agent follows SKILL.md guidance; malformed instructions could cause unsafe operations |
| Agent → Shell wrappers (.sh) | Shell wrappers execute `pio` CLI commands; unvalidated project_dir could enable path traversal |
| Agent → Serial port hardware | Upload/flash operations modify device firmware; incorrect port or binary could brick devices |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | Tier 3 shell wrappers | mitigate | SKILL.md instructs agent to validate project_dir contains platformio.ini before invoking any shell wrapper; warn user when operating without MCP server safety guardrails |
| T-01-02 | Tampering | Shell wrapper scripts in assets/ | mitigate | Scripts are version-controlled; SKILL.md instructs agent to verify scripts exist before execution; reject scripts from untrusted paths |
| T-01-03 | Information Disclosure | Serial port enumeration (discover.sh) | accept | Port enumeration via `pio device list` is read-only system info; no sensitive data exposed; low-value target |
| T-01-04 | Denial of Service | Upload/flash to wrong device | mitigate | SKILL.md mandates ask-before-flash gate (D-04); requires port discovery before upload (D-05); agent must confirm target port and environment with user |
| T-01-05 | Elevation of Privilege | Shell wrappers running pio with inherited user permissions | accept | pio CLI runs under same user privileges as agent; no privilege escalation; user must have pio in PATH intentionally |
| T-01-SC | Tampering | npm package install (Tier 2) | mitigate | npx runs from npm registry; SKILL.md instructs agent to use exact package name `pioarduino-mcp-server`; user confirmation required before install |
</threat_model>
